# Third-party software and data

The MIT license covers this repository's original code and documentation. It does not relicense NVIDIA model weights, hosted services, OpenScPCA/ScPCA source data, or third-party software. Obtain those materials from their original sources and follow their own terms. No third-party library source or model weights are bundled.

Used tools include NVIDIA Nemotron and CUDA, PyTorch, Hugging Face Transformers/PEFT/Accelerate, mamba-ssm, causal-conv1d, Scanpy, AnnData, NumPy, pandas, SciPy, igraph/Leiden, UMAP, scikit-learn, Matplotlib, lm-format-enforcer, jsonschema, DeepEval, OpenAI's Python API client. These names identify dependencies and experimental roles.

Sources: https://openscpca.readthedocs.io/ ; https://scpca.readthedocs.io/ ; https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Nano-4B-BF16 ; https://github.com/huggingface/peft ; https://github.com/state-spaces/mamba ; https://deepeval.com/docs/metrics-llm-evals .
