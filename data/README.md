# External data

Obtain the original OpenScPCA project SCPCP000004 matrix and metadata through its data-access process. Set `SCPCA_H5AD` and `SCPCA_METADATA` before opening the local data-preparation notebook. `.env.example` documents settings but is not automatically loaded.

Raw matrices, metadata, expert workbooks/ledgers, original model responses, saved coordinates and model weights are not bundled. The training and inference notebooks require separately prepared private input packages, as described in [running the study](../docs/RUNNING.md). Obtain permission for any expert-contributed material before redistributing it. Keep local data and generated packages out of version control.
